# deney — experiments

*Deney* is Turkish for experiment. Each experiment is a folder here and a
branch of its own, so its code, data and results never mix with the
engine's or with each other's.

## Convention

- **Folder:** `deney/<id>-<slug>/`, for example `deney/e0-switch-ceiling/`.
  Inside:
  - `README.md`: question, definitions, method, data, results, caveats,
    what comes next;
  - `data/` with a `manifest.json` naming where every file came from;
  - the code, as its own project (its own Cargo workspace or Python
    environment), never a member of the engine's build;
  - `results/`: the outputs the README cites, regenerated by one command.
- **Lineage:** branch `deney/<id>-<slug>`, created from the branch whose
  document defines the experiment, and recorded in the experiment's
  README (parent branch and commit). A result that changes a document is
  written into that document on the experiment's branch, so the parent
  receives it by merge.
- **Reproducible:** the README gives the exact commands; data copied from
  elsewhere is copied unchanged, with its origin in the manifest.
