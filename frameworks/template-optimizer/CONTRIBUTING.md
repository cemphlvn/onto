# Contributing

Open an issue describing the template type, the independent evaluation data,
and the intended admission policy. Keep application metrics in the application;
this package must not invent success from model confidence alone.

Run `python -m unittest discover -s tests -v` before a pull request. New policy
checks need a test that shows an otherwise attractive candidate being rejected.
When onto publishes its application bindings, integrate through that public API
and test against an actual `.onto` category.
